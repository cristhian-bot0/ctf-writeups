# CTF Writeups — Cristhian Taipe

Writeups from CTF competitions and training-lab chains I've solved. I'm a CS student (UNSA, Peru) focused on full-stack development and offensive security — most of these trace a chain from recon to the final flag, with the exploit scripts I used to get there.

Each challenge folder keeps the same structure: `WRITEUP.md` (the full walkthrough) plus any small solver script referenced in it. Internal notes, downloaded challenge binaries/assets, and competitions whose rules require writeups to stay private are not published here.
